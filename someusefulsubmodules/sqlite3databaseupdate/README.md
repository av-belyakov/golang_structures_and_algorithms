# Модуль sqlite3databaseupdate

Модуль UpdateSqlite3 выполняет модификацию базы данных Sqlite3 в которой содержится информация о _caseId_ получаемых от TheHive и _eventId_ получаемых от MISP, эти данные содержатся в колонках _caseId_ и _eventId_ соответственно. Эти два id коррелируются между собой. Можно выполнять поиск _eventId_ по _caseId_ и на оборот.
Модуль добавляет колонки _time_ и _source_ и наполняет их. В процессе выполняются следующие шаги:

1. Проверяется что таблица БД содержит поля _caseId_ и _eventId_ и в ней отсутствуют поля _time_ и _source_;
2. Формируется список _eventId_ по которому будет выполнятся поиск;
3. Выполяются запросы к MISP что бы получить **event** по каждому eventId;
4. В map приложения, сформированной путем чтения файла **sources.yml** выполняется сравнение поля _organization_ события MISP **event** со значениями с целью поиска наименования source;
5. При успешном поиске в колонку _source_ добавляется имя источника, а в колонку _time_ время в формате RFC3339.

### Используемые переменные окружения

В файле _.env_ который должен находится в корне модуля должны быть следующие необходимые переменные:

- GO_SQLITE3DATABASEUPDATE_MISPTOKEN - содержит токен доступа к MISP
